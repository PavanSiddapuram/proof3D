# apps/web

React + TypeScript + Vite + Three.js dashboard: paste a URL, watch stages live, open the scorecard, and compare single-photo with Proof3D next to the held-out photo from the same camera.

**Not built yet** (PRD weeks 2-4). It will read `GET /jobs/{id}`, `GET /assets/{id}/scorecard` and `GET /products/{id}/compare` and show only stored measurements.
